# Agents Guide

## Code Style Preferences

- Prefer smaller, modular files over large monolithic files
- Keep components loosely coupled
- Extract reusable views into their own files
- One primary view per file when possible

## TestFlight

Run `./testflight.sh` on the Mac mini. It uses fastlane and needs no prompts. Read "Building on this Mac instead" in `docs/testflight-ci.md` first.
